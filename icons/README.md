# Icons

Drop icon image files here to have them appear on the homepage. Any file that is
missing simply renders as a plain colored circle (the label color), so you can add
icons incrementally.

Filenames the homepage looks for (`/icons/<name>`):

## Nav / branding
- `solarspell-logo.png`       (small logo in the top nav)
- `solarspell-logo-full.png`  (footer logo)
- `asu-logo.png`              (footer ASU logo)
- `hero.png`                  (hero banner image below the nav)
